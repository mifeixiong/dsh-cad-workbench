# 参考图对位建模

> 适用：只有参考图（视频截帧、照片、扫描图纸）或图纸不全，要还原外形/布置，并且**必须能证明像**。
> 不适用：尺寸齐全的单零件（走 `cad-modeling-workflow` 的 M1）。

## 0. 开工硬关卡

做不完全部四项就别建模，否则后面每一轮返工都在补这四项：

1. **图源清单**：每帧一行 —— 帧 id、视角（side/top/front/section）、拍摄距离/透视程度、被遮挡部位。至少要有侧视 + 一张能定横向的视图（俯视或正视）。
2. **主尺度**：总长/型宽/型深/关键标高（甲板、水线）从资料或图纸取，不许从图上"估"。
3. **坐标系**：先定 `u/v/w` 与原点（例：`u=x` 艉封板 0 → 艏尖 LOA；`v=z` 基线 0；`w=y` 右舷正），单位统一 m。
4. **判据**：明确"什么算过"——目标带（每项 ±tol）与轮廓容差（每格多少米），写进计划。

## 1. 标定（calibrate）

每帧两轴各两个基准点，形如：

```json
cadw_ref(project:"jidi", action:"calibrate", frame:{
  "id":"frame_05","path":"…/frame_05.png","view":"side",
  "u":{"px0":35,"m0":0,"px1":581,"m1":89.95},
  "v":{"px0":300,"m0":-0.3,"px1":220,"m1":13.75}})
```

判定标准（工具会写入 `checks`）：

| 检查 | 判据 | 不达标怎么办 |
|---|---|---|
| 两轴 m/px 一致性 | 相差 < 10% | 正投影图通常接近 1；差太多说明两个基准点不在同一平面，重选 |
| v 轴斜率符号 | 应为负 | 为正说明 v 定义反了 |
| 基准点在画面内 | px 落在图像尺寸内 | 换点 |
| 互校 | 用标定反算一个**已知**尺寸（如总长、甲板高），误差 < 1% | 重标或换帧 |

**只用一个基准点定比例、另一点靠"看起来"是不行的**：两点必须都是可复现的特征（艉端面、艏尖、甲板线、水线），并写进 `note`。

## 2. 量测（measure）

掩膜选择（`masks` 里定义一次，之后按名字引用）：

| 掩膜 | 规则 | 用途 | 坑 |
|---|---|---|---|
| `hull` 红壳 | `type:color, r_min:110, r_minus_b_min:55, r_minus_g_min:55` | 船体上缘、艉部线型 | 上层建筑红顶也是红的 → 必须加 `v:[null,15.9]` 上限或 ROI |
| `white` 白体 | `r/g/b_min:185, range_max:22` | 烟囱、驾驶室、球罩 | 玻璃带/阴影不是白 → 量"最长白条"而不是全包 |
| `white_loose` | `r/g/b_min:160, range_max:55` | 有阴影的曲面（球罩、机库） | 会吃进天空/水面，必须配 ROI |
| `dark` 深色 | `type:dark, r_max:70…` | 黑冠、舷窗、桅 | 阴影也算深色 |
| `yellow` | `r_min:170, g_min:120, b_max:120` | A 架、吊臂 | 白色高光会断条 |
| `ink` 墨迹 | `type:ink, tol:18` | 黑白图纸/线条图 | 背景不干净时先裁 ROI |

四种量测的用法：

| kind | 什么时候用 | 关键字段 | 读什么 |
|---|---|---|---|
| `profile` | 轮廓（上缘/下缘随长度变化） | `u:[起,止], step, v_filter, compare:["vmax"]` | `points:[[u, vmin, vmax]]` |
| `bbox` | 构件外形（烟囱、机库、球罩） | `roi:{u:[], v:[]}`, `mask` | `du/dv/u0/u1/v0/v1/cu/cv` |
| `extent` | 单点高度/宽度（某 u 处的上下缘） | `at_u` 或 `at_v`, `band`, `v_filter` | `v0/v1` 或 `u0/u1` |
| `coverage` | 连续性（舷墙、走廊白条有无断口） | `u:[], step, v_filter` | `min_ratio`, `gaps` |

**固化目标带**：量测项里写 `target:{name:"funnel_len", part:"funnel casing", field:"dx", model_field:"dx", tol:0.3}`，
工具把"参考值 ± tol"存成 `project.targets`，下一步 `cadw_diff` 直接用它判 PASS/FAIL。参考值不许手抄，
否则改一次量测就要改一处表。

**口径三条铁律**：

1. 参考掩膜量的是**哪一种颜色/哪一段表面**，模型侧就要用 `model_filter` 限定到**对应的部件**（例：红壳 ↔ `model_filter:"hull loft"`）。
   不限定就会出现"模型把舷墙算进上缘，恒定 +1.0 m"这种假差异。
2. 单色掩膜通常只有一边可靠：只比一边（`compare:["vmax"]`），另一边用另一种掩膜单独量。
3. 目标带的 tol 是**测量不确定度**，不是"希望误差"。像素级 ±2 px × 0.17 m/px ≈ 0.35 m，别写 0.05。

## 3. 网格（render）

- 视图：`side`(x-z) 定轮廓与上层建筑；`top`(x-y) 定横向与左右对称；`front/rear`(y-z) 定跨距、双吊舱、机库门；局部 `section` 用切片。
- 格号：列 = u 每 `u_step` 一个字母（A 起），行 = v 每 `v_step` 一个数字（1 起）。例：`K5` = x 50–55 / z 20–25。
- 三张图配合看：`*_model_side.png`（模型+部件框+格号）、`*_ref_<frame>.png`（参考帧+同一套格号）、`*_zones.png`（责任分区）。

**用户圈注 → 格号 → 工单**三步：读格号 → 查责任区（哪个模块/agent）→ 写"参考边界 / 现模型边界 / 期望"。

## 4. 差分（diff）

```
cadw_diff(project:"jidi", report:"out/report.json", mesh:"out/model.json",
          targets:[…], profile_measures:["shell_upper"], tolerance:1.0)
```

读表顺序：

1. **先看 MISSING**：模型在该格没有几何 → 部件缺失或整体错位，比"偏几米"严重。
2. **再看轮廓行的符号**：所有格同号同量级 → **口径问题**（掩膜 vs 部件命名、是否含舷墙），不是形状错。
3. **再看单格 FAIL**：局部形状错（台阶位置、烟囱收分、艏柱弧度）。
4. **最后看 WARN**：接近容差，记录在案，等下一轮一起看。

模型侧包络优先用 `mesh`（三角网格）而不是 `parts`（bbox）：
bbox 会把"被切掉的尾部"当成满高，产生 ±4 m 的假偏差。

## 5. 先过对抗审查，再谈像不像

差分只回答"像不像"，不回答"结构对不对"。拿到 FAIL 之前/之后都要跑一次：

```
cadw_audit(parts:…, facts:…, diff:…, support_planes:[0,9.30,13.75,19.15,22.95])
```

**P0 未清零前不要改形状**：悬空/埋入/过定义/破面会在每一轮迭代里反复制造新差异。
细节见 `cad-adversarial-review` 技能。

## 6. 派工（dispatch）

```
cadw_dispatch(project:"jidi", zones:[…], diff:…, audit:…,
              brief:{project_root, must_read, frames, build_cmd, verify_cmds},
              recursion:{allow:true, max_depth:2, split_threshold:6})
```

一个区一个 agent，一个 agent 一个写作用域。工单必带：本区未通过项、唯一写作用域、必读清单、
自检命令与达标线、递归条款、"先 `list_subagent_models` 再选模型"的硬规则、回报格式。

**模型选择**（血泪）：不显式校验就用不可用组合时，子智能体会直接失效且不留收尾消息；
默认继承父会话模型，失败按"继承默认 → 同 provider 另一模型 → 拆小任务"回退。

## 7. 每轮迭代只做三件事

1. 重新 `render`（网格）+ `diff`（数字）→ 确认本区 FAIL 清单变短。
2. 跑 `audit` → P0 必须为 0。
3. 把新差异写回 `DECISIONS.md` 式的裁决记录（为什么改这个数、依据是哪一帧哪一格）。

## 8. 常见误用

| 误用 | 症状 | 正解 |
|---|---|---|
| 没标定就量 | 每轮数字都在变 | 先 calibrate，用已知尺寸互校 |
| 只用侧视网格 | 横向/俯视错误永远查不出 | side + top + 一个正视图 |
| 掩膜口径与部件命名不一致 | 全格恒定偏差 | 用 `model_filter` 对齐口径 |
| 用 bbox 当轮廓 | 被切掉的部位显示满高 | 用 `mesh` |
| tol 写得像愿望 | 全 FAIL，最后只能改 expect | tol = 测量不确定度 |
| 先改形状后修悬空 | 改十遍还是错 | 先 P0 |
