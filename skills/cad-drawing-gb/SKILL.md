# GB/T 机械制图规范（工程图与 DXF）

## 第一角法

- 六个基本视图：主视、俯视（主视**下方**）、左视（主视**右方**）、右视（主视**左方**）、
  仰视、后视。
- 插件默认把俯视放在主视下方、右视放在主视左方；`first_angle:false` 才按第三角法。
- 等轴测图放右下角作参考，不参与投影关系。

## 图幅与比例

| 图幅 | 尺寸 (mm) |
|---|---|
| A4 | 297 × 210 |
| A3 | 420 × 297 |
| A2 | 594 × 420 |
| A1 | 841 × 594 |
| A0 | 1189 × 841 |

- 优先 1:1；装不下按 GB/T 14690 选 1:2、1:5、1:10、2:1、5:1。
- 插件选 `gb_a3.drwdot` 等模板；图幅与 `sheet` 参数必须一致，否则视图会挤在角落。

## 图层 / 线型 / 线宽

SolidWorks 中文 DXF 常用图层（插件规则已做别名映射）：

| 用途 | SolidWorks 图层 | GB/T 线型 |
|---|---|---|
| 可见轮廓 | 轮廓实线层 / SLD-0 | 粗实线 0.5–0.7 mm |
| 细线/剖面线 | 细线层 / 剖面线层 | 细实线 0.25 mm |
| 中心线/轴线 | 中心线层 | 细点画线 |
| 虚线（不可见轮廓） | 虚线层 | 细虚线 |
| 尺寸 | 标注层 | 细实线 |
| 文字 | 文字层 | — |

`cadw_review` 默认要求 OUTLINE / CENTER / HIDDEN / DIM 四类可识别（含中文别名），
缺了给 WARN；零长线、重复线、单位错误会给 FAIL/WARN。

## 文字与标注

- 字高 ≥ 2.5 mm（A3/A4 常用 3.5 mm）；同一张图字高不超过 2 种。
- 尺寸线不与轮廓线重合；尺寸数字朝上或朝左，避免倒写。
- 圆/圆弧标直径 `Ø`、半径 `R`；螺纹标 `M`；角度带 `°`。
- 基准/形位公差/粗糙度 v0.1 不自动生成，需要时提醒用户手工补。
- 尺寸链要闭合可解，不要出现"总长 + 分段"双重标注冲突。

## 出图验收清单

1. `cadw_drawing` 返回 `view_count >= 4`（主/俯/右/等轴测），`warnings` 为空或已解释。
2. PDF 打开能看到标题栏、视图、主要尺寸。
3. DXF 审查：`verdict` 为 PASS，或 WARN 项能逐条解释（常见：没有标注尺寸）。
4. STEP/STL 导出的包围盒与零件实测一致。
5. 图纸文件名与零件名一致，产物在 `cad-output/drawings/` 下。

## 常见缺陷与修法

| 症状 | 原因 | 修法 |
|---|---|---|
| 视图跑到图框外 | 图幅/模板与坐标不匹配 | 指定正确 `sheet`，或换 `gb_a3` 模板 |
| 只有 1 个视图 | 逐视图插入失败后退化 | 看 `warnings`；确认中文视图名可用 |
| 尺寸为 0 | 零件草图没有标注尺寸 | 在零件里标尺寸，或出图后手工标 |
| DXF 单位错 | 导出未写 \$INSUNITS | 用工程图导出 DXF；或设置单位 |
| 中文字体缺失 | DXF 字体未嵌入 | 用 SHX/TTF 指定字体，或转 PDF 交付 |
